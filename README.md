# Менеджер задач с трекингом времени

**Коротко**: Разработала консольное приложение для управления задачами с поддержкой эпиков, подзадач, приоритизации по времени, хранения истории просмотров и сохранения данных в файл.

## Что делала я

- Реализовала полную объектно-ориентированную архитектуру приложения с наследованием (Task → Subtask, Epic)
- Разработала систему управления статусами задач (NEW, IN_PROGRESS, DONE) с автоматическим пересчетом статусов эпиков
- Внедрила трекинг времени для задач: начало, продолжительность, расчет времени окончания
- Реализовала механизм приоритизации задач по времени начала с проверкой на пересечения
- Создала кастомную двусвязную список-структуру для хранения истории просмотров
- Реализовала файловое хранилище с сериализацией/десериализацией задач в CSV-формат
- Написала комплексные JUnit-тесты для всех компонентов системы (покрытие > 90%)
- Спроектировала иерархию интерфейсов (TaskManager, HistoryManager) с реализациями

## Инструменты

- **Язык программирования**: Java 17+
- **Библиотеки**: JUnit 5 (тестирование)
- **Паттерны проектирования**: Стратегия, Фабричный метод, Интерфейсы
- **Структуры данных**: HashMap, LinkedList (кастомная реализация), TreeSet
- **Время и дата**: java.time API (LocalDateTime, Duration)
- **Работа с файлами**: BufferedReader/BufferedWriter, File I/O
- **Система контроля версий**: Git
